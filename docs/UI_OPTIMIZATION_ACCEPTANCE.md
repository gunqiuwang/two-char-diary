# UI 优化验收标准

## 一、阴影系统 ✅

### 验收项目
| 项目 | 验收标准 | 测试方法 |
|------|----------|----------|
| 米字格阴影 | 默认状态有极淡阴影 (0.03透明度) | 观察米字格是否有立体感 |
| 米字格激活态 | 激活时阴影加深 (0.08透明度) | 点击米字格观察阴影变化 |
| 米字格填充态 | 填充后有轻微阴影 (0.04透明度) | 输入文字后观察 |
| 候选词阴影 | 默认有极淡阴影 | 观察灵感词区域 |
| 候选词点击 | 点击时阴影加深 | 点击灵感词观察 |
| 分享卡片 | 有明显阴影 (0.05透明度) | 观察卡片是否有浮起感 |
| 日历详情卡 | 有明显阴影 | 点击有记录的日期观察 |
| 历史记录项 | 有轻微阴影 | 进入历史页面观察 |

### 验收项目
| 项目 | 验收标准 | 测试方法 |

## 四、动画优化 ✅

### 验收项目
| 项目 | 验收标准 | 测试方法 |
|------|----------|----------|
| 字符出现动画 | 从下方滑入+淡入，有轻微回弹 | 输入文字观察出现效果 |
| 动画时长 | 300ms，流畅不拖沓 | 感受动画节奏 |
| 铜钱点击 | 点击时有摇晃动画 | 点击铜钱观察 |
| 摇晃效果 | 左右摇摆后回正 | 观察摇晃幅度和节奏 |
