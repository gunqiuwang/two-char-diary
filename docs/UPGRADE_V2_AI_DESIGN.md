## 1. 设计总原则

二字爻记的立身之本是「极简、克制、安静」。AI 不能喧宾夺主，三条铁律：

1. **AI 只做注脚，不做主角** —— 二字仍是用户亲手写的，卦仍是铜钱起的，AI 只在旁边轻声注解
2. **离线永远可用** —— 断网、额度耗尽、并发超限时，产品完整功能不残缺，AI 层静默降级
3. **每日一次，不刷不卷** —— 所有 AI 内容按日生成并本地缓存，不做无限重生的按钮游戏

## 2. 功能设计（按优先级）

### F1 爻解 · AI 今日注脚 ★核心

起卦完成后，卦辞爻辞之下多一栏「爻解」：AI 结合**当日二字 + 卦名 + 卦辞 + 节气/节日**，生成一段 60–100 字的现代文注脚。

- 语气设定（写进 system prompt）：像一个懂《易经》的安静朋友，就字解字、就卦说卦；只做观照与联想，**不预测吉凶、不给行动指令、不提财运疾病婚姻**
- 每卦每日只生成一次，随记录存入本地；离线时该栏不显示（而非报错）
- 内容下方常驻浅灰小字「AI 生成 · 仅供文化参考」（合规标识，见 §5）

**为什么是它当核心**：它把「二字」和「一卦」这两个原本并列的模块缝合起来，是产品逻辑上最自然的一块拼图，且纯文本、成本最低、风险最可控。

### F2 灵感词 · 动态生成

现有灵感词是 90 个静态词 + 节气词表。升级为：每日首次进入编辑态时，AI 按**季节、节气、干支日、时辰**生成 8 个二字灵感词，与静态词库混合展示。

- 生成结果按日缓存（`inspire_cache` 键），同一天不重复消耗 Token
- 失败/离线时完全退回现有静态词库，用户无感知
- 「换一批」按钮仍走本地随机，不额外消耗额度

### F3 笺纸 · AI 意境海报 ★视觉爆点

分享页新增一种纸张风格「AI 笺纸」：用混元生图按当日二字 + 节气生成一张**水墨/宣纸意境底图**（如「盛夏」→ 荷叶莲蓬水墨小品），再叠加现有 Canvas 排版（米字格二字、卦线、卦辞），生成独一无二的当日海报。

- 底图生成**必须走云函数**（生图模型仅支持服务端调用），生成后传云存储，fileID 本地缓存
- 每日每用户最多生成 1 张，防止额度被刷；生成中展示「研墨中…」占位，失败退回四种静态纸张
- 海报角落保留「AI 绘」小印（合规标识 + 风格化一举两得）
- 分享卡封面图自动使用生成的海报

### F4 岁物集 · 月度回顾

年历页新增「岁物」入口：每月 1 日可生成上月的**月度小传** —— AI 把当月所有二字串成一段 150 字以内的散文式回顾（如「七月是萤火、纳凉、骤雨的三十二天」）。

- 按月缓存；不足 5 天记录时不开放（避免编造）
- 这是对「坚持记录」的奖励机制，提升留存的钩子埋在这里

### F5 云同步 · 匿名备份（顺带根治审计 P1-4.6）

接入云开发后自然获得的能力：匿名登录 + 云数据库，本地 `diary_data` 每次变更后静默增量同步。

- 本地仍为一等公民（先写本地再同步），换机/重装后首次打开自动恢复
- 设置页提供开关，默认开启并在隐私指引中说明
- 同时根治「分享 URL 明文」：分享改为生成 24h 有效的 share token，分享页凭 token 从云函数拉快照（v2 可做，也可延后至 v2.1）

### 明确不做

- ❌ 每日运势推送 / 解签问事（违背产品定位，审核高危）
- ❌ AI 对话聊天（与「克制」调性冲突，Token 消耗不可控）
- ❌ 无限重生海报（额度风险 + 稀释稀缺感）
- ❌ 用户画像、个性化推荐（隐私面扩大，收益不明）

### 3.2 文本模型调用（小程序端直连）

```js
// utils/ai.js —— 基础库需 ≥ 3.15.1
const model = wx.cloud.extend.AI.createModel('cloudbase')  // 优先消耗免费额度

async function dailyAnnotation({ words, hexName, hexCi, special }) {
  const res = await model.streamText({
    data: {
      model: 'hy3',           // 并发超限时切换 hy3-preview
      messages: [
        { role: 'system', content: '你是一位懂《易经》的安静朋友。根据用户的当日二字与卦象，写一段60-100字现代文注脚。只观照与联想，不预测吉凶，不给建议，不提财运疾病婚姻。语气克制温润。' },
        { role: 'user', content: `二字：${words}；卦：${hexName}，卦辞：${hexCi}${special ? `；时令：${special}` : ''}` }
      ]
    }
  })
  // 流式接收，200ms 节流 setData；完成后再做服务端安全检测
}
```

要点：
- 免费额度**只允许**从小程序端 `wx.cloud.extend.AI` 或云函数 `wx-server-sdk` 调用。**不要**在小程序/云函数之外直接 HTTP 请求 `https://cloud1-d6gfjpnx82bd1357a.api.tcloudbasegateway.com/v1/ai/cloudbase` —— 官方专项治理公告明确此为违规消耗免费额度，可能被停用
- `EXCEED_CONCURRENT_REQUEST_LIMIT` → 指数退避重试 2 次 → 切 `hy3-preview` → 仍失败则静默降级
- Token 用量在云开发控制台「AI 模型用量」监控，80%/90%/100% 有公众号提醒

### 3.3 生图调用（云函数）

```js
// cloudfunctions/genImage/index.js
const cloud = require('wx-server-sdk')
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV })

exports.main = async (event) => {
  // 1. 频控：openid + date 查库，每日 1 张
  // 2. 生图
  const imageModel = cloud.extend.AI.createImageModel('hunyuan-image')
  const res = await imageModel.generateImage({
    model: 'HY-Image-3.0-Plus-4090-Tob-v1.0',
    prompt: `中国传统水墨小品，宣纸质感，留白构图，主题意象：${event.words}${event.special ? '，时令：' + event.special : ''}，色调淡雅，无文字无人物`,
    size: '1024x1024'
  })
  // 3. 内容安全检测（imgSecCheck）
  // 4. 上传云存储，返回 fileID；客户端 wx.cloud.downloadFile 后叠加 Canvas 排版
}
```

图生图（`HY-Image-v3.0-I2I-ToB-v1.0.1`）留作后续玩法：以宣纸纹理为垫图控制风格一致性。

## 4. 成本与额度测算（10 亿 Token / 10 万张图）

- F1 爻解：单次约 400 input + 200 output Token。1 万日活 × 每日 1 次 ≈ 600 万 Token/天，**资源包可撑约 1600 天** —— 额度完全不是瓶颈
- F3 生图：1 张/人/日，10 万张 = 1 万日活 × 10 天。**生图是唯一需要盯的额度**，频控必须做实；耗尽后云函数内切换自备图床 + 静态纸张兜底
- 真正约束是**并发**：成长计划共享并发，高峰期 `EXCEED_CONCURRENT_REQUEST_LIMIT` 常见，重试 + 降级链路是刚需而非可选项

## 5. 合规清单（提审前必办）

1. **类目**：确认小程序类目含工具/文娱/深度合成类，否则成长计划与 AI 功能审核都会卡
2. **AI 标识**：爻解下方「AI 生成 · 仅供文化参考」；AI 海报角落「AI 绘」印章 —— 符合《人工智能生成合成内容标识办法》显式标识要求
3. **内容安全**：AI 输出服务端/客户端双重把关；生图走 `imgSecCheck`；prompt 已做方向约束但仍需检测兜底
4. **隐私指引**：新增「AI 功能会将当日二字、卦象发送至云开发 AI 服务」「开启云同步后记录将加密存储于云端」两条
5. **文案红线**：爻解与岁物集的全盘文案保持「文化注脚」定位，system prompt 已禁止预测性表述，审核物料中同步准备说明
6. **额度合规**：免费额度只在小程序端与云函数内消耗，不接任何外部工具

## 6. 验收标准（v2.0 DoD）

- 断网状态下：记录、起卦、年历、分享四种静态纸张全部正常，AI 区域静默隐藏
- 额度耗尽模拟：所有 AI 功能无报错、无白屏，降级到 v1 体验
- 爻解生成 ≤ 5s 首字；海报生图 ≤ 30s，有进度反馈
- iOS / Android 真机各一轮完整流程（记录 → 起卦 → 爻解 → AI 海报 → 保存 → 分享）
- 云同步：A 设备记录 → B 设备首次打开自动恢复
- 开发者工具「代码质量」「体验评分」无新增红项
