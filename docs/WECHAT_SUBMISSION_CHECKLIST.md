## B. 微信后台资料

- [ ] 小程序名称统一使用“二字爻记”
- [ ] 头像清晰，在圆形裁剪和小尺寸下仍可识别
- [ ] 简介强调“二字日记、传统文化灵感记录”

- [ ] 截图覆盖：首页、年历、分享卡、设置
- [ ] 版本说明准确，不出现夸张占卜承诺

推荐简介：

> 每天用两个字记录心情，再以一卦作为传统文化注脚。记录默认保存在本机，可生成分享卡片。

避免使用：

- 算准未来
- 改运
- 测疾病、财运、婚姻结果
- 保证吉凶或成功率

## C. 用户隐私保护指引

根据实际 API 行为核对微信后台隐私声明：

- [ ] 日记和设置默认存储在用户本机
- [ ] 用户主动点击“保存”时，使用相册写入能力
- [ ] 用户主动分享时，二字和基础卦象信息通过微信分享
- [ ] 不声明项目完全不会传输任何内容，因为主动分享会通过微信发送
- [ ] 未使用手机号、位置、相机、麦克风、联系人和登录身份接口

代码涉及：

```text
wx.saveImageToPhotosAlbum
wx.openSetting
wx.showShareMenu
```
