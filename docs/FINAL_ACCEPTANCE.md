## 七、已知限制

1. **提醒功能**：仅保存设置，未实际注册通知
2. **天干地支**：仅计算年柱，不含月柱、日柱
3. **历史页面**：不支持暗色模式（待优化）
4. **字体加载**：依赖CDN，离线时降级为系统字体
